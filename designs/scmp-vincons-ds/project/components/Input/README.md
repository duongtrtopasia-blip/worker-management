# Input

Ô nhập liệu một dòng, luôn đi kèm `<label>` hiển thị phía trên (không dùng placeholder thay cho label).

- Cao 40px, viền `line-strong`; rê chuột thì viền chuyển `ink-muted`; khi focus viền `brand-blue` kèm vòng `brand-blue-line` 3px.
- Lỗi: viền `danger`, nền `danger-soft`, dòng báo lỗi bên dưới màu `danger` và `aria-invalid="true"`.
- Dòng gợi ý: `caption`, màu `ink-muted`.

Viết tay theo `src/components/ui/input.tsx` và `label.tsx`.
