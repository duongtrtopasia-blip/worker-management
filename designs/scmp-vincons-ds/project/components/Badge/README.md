# Badge

Nhãn trạng thái ngắn, gồm một chấm tròn và chữ. Không bao giờ để badge chỉ có màu mà không có chữ.

| Tone | Nghĩa |
|---|---|
| success | Đủ hồ sơ, thẻ còn hạn, đang làm việc |
| warning | Sắp hết hạn (≤ 30 ngày) |
| danger | Hết hạn, thiếu hồ sơ, bị khóa |
| info | Đã in thẻ, mới import |
| neutral | Nghỉ việc, nháp |

Thay cho các class rời như `text-amber-700 bg-amber-100` và `text-red-700 bg-red-100` trong code cũ.
